# 🏥💻 Sistema de Gestión Hospitalaria - CLI Java 🩺⚙️  

## 📖 Descripción  
Este proyecto es un **Sistema de Gestión Hospitalaria** desarrollado en **Java**, que funciona completamente desde la **ventana de comandos (CLI)**.  

Está basado en conceptos fundamentales de:  
- **Estructuras de datos** para almacenar y manejar la información eficientemente.  
- **Programación Orientada a Objetos (POO)** para organizar el código en clases y objetos que representan entidades reales (pacientes, médicos, etc).  

El sistema permite gestionar registros hospitalarios, revisar turnos, y administrar recursos de forma sencilla y funcional sin interfaz gráfica.  

---

## ⚙️ Funcionalidades principales  
- Gestión de pacientes: alta, modificación, baja y consulta.  
- Gestión de médicos y especialidades.  
- Programación y control de turnos.  
- Manejo de inventario de recursos hospitalarios.
